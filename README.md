# مختبر الدرس (Python)

باك إند FastAPI + واجهة React/SVG/GSAP. كل حاجة بتشتغل بـ:

```bash
python main.py
```

أول مرة بيسطّب المكتبات، وبيسألك عن المفاتيح (اختيارية)، وبيبني الواجهة ويفتح http://localhost:8787.

## المطلوب
- Python 3.9+
- Node.js **مرة واحدة** لبناء الواجهة. لو معاك مجلد `dist` جاهز (من المشروع القديم مثلًا: `client/dist`) انسخه في `client/` ومش محتاج Node.

## الإعدادات (ملف `.env` في جذر المشروع)
| المتغير | الاستخدام |
|---|---|
| `GEMINI_API_KEY` | توليد الدروس من اسم أو نص + سؤال المدرس (اختياري) |
| `OPENROUTER_API_KEY`, `OPENROUTER_MODEL` | بديل أوتوماتيك لو Gemini وقع (أو بديل كامل لو مفيش مفتاح Gemini) |
| `LLM_PROVIDER` | `auto` (Gemini ثم OpenRouter، الافتراضي) / `openrouter` / `gemini` |
| `LLM_FALLBACK_COOLDOWN` | ثواني البقاء على OpenRouter بعد وقوع Gemini (الافتراضي 300) |
| `CARTESIA_API_KEY`, `CARTESIA_VOICE_ID` | الصوت (من غيرهم بيرجع لصوت المتصفح) |
| `CARTESIA_MODEL`, `CARTESIA_LANGUAGE`, `CARTESIA_VERSION` | `sonic-3` / `ar` / `2026-03-01` |
| `PORT` | البورت (8787) |
| `DB_PATH` | مكان ملف قاعدة البيانات (اختياري، الافتراضي `data/lesson_lab.db`) |

## الهيكل
```
main.py               التشغيل (تسطيب + بناء الواجهة + سيرفر)
backend/app.py        FastAPI: /api/lessons, /api/generate, /api/regenerate, /api/ask, /api/tts
backend/llm.py        طبقة الموديل: Gemini ثم تحويل كامل على OpenRouter لو وقع
backend/gemini.py     توليد الدروس + المدرس
backend/tts.py        Cartesia (الصوت بيتخزّن في SQLite)
backend/db.py         قاعدة بيانات SQLite (جدول tts_audio) + نقل tts-cache القديم
backend/validator.py  فحص الـ Spec وتنظيف الـ SVG
lessons/*.json        الدروس (المولّدة بتتحفظ هنا)
data/lesson_lab.db    قاعدة البيانات (بتتعمل أوتوماتيك)
client/               الواجهة (نفس الكود بدون تغيير)
```

وضع التطوير: `python main.py --dev` (محتاج Node).

## الحكاية (Story)
الحكاية **مش بتشرح الدرس**. الشرح مكانه شرح أجزاء الرسمة (`parts`) والأسئلة (`checks` و`quiz`).
الحكاية دلوقتي موقف من حياة الطفل اليومية:
- **هوك**: أول فقرة موقف مفتوح بيشد الطالب من أول جملة وبينتهي بسؤال (؟).
- **استخدام في الحياة**: الشخصية بتستخدم فكرة الدرس عشان تحل موقف حقيقي (البيت، المدرسة، السوق، الشارع…).
- **Payoff**: آخر فقرة بتجاوب على سؤال الهوك وبتبيّن الدرس فادنا إزاي في حياتنا.
- الأنيميشن على الرسمة **اختياري**: بيشتغل بس في الفقرات اللي الحدث بتاعها ظاهر في الرسمة.

في `story_arc` بقى فيه حقلين جداد: `hook` و`life_use`، والـ validator بيرفض أي حكاية من غير هوك أو فيها عبارات شرح زي "هنتعلم" و"بنسميه" (ويعيد التوليد مرتين).

## قاعدة البيانات (SQLite)
الصوت اللي بيرجّعه Cartesia بيتخزّن في جدول `tts_audio` (النص، اللغة، الصوت، الموديل، الملف نفسه، عدد مرات الاستخدام) بدل مجلد `tts-cache/`.
أول ما السيرفر يشتغل، ملفات `tts-cache/*.mp3` القديمة بتتنقل للقاعدة مرة واحدة (من غير ما تتمسح)، ومن بعدها تقدر تمسح المجلد.
إحصائيات الكاش: `GET /api/health` (حقل `tts_cache`).

## لو Gemini وقع (OpenRouter)
لو Gemini رجّع "high demand" أو 503 أو quota أو تايم أوت، `backend/llm.py` بيحوّل **كل** الطلبات على OpenRouter (توليد الدروس وسؤال المدرس) ويفضل عليه `LLM_FALLBACK_COOLDOWN` ثانية، وبعدها بيجرّب Gemini تاني. ضيف `OPENROUTER_API_KEY` في `.env`. لو عايز OpenRouter بس: `LLM_PROVIDER=openrouter`. حالة الموديل الحالية: `GET /api/health` (حقل `llm`).

## تحديث الدروس القديمة بالطريقة الجديدة
الدروس اللي من غير حكاية/هوك (علامة "(قديم)" في القايمة) بتتحدّث من زرار **"حدّث الدروس القديمة"** (جوه "اشرحلي درس جديد")، أو بـ `POST /api/regenerate {"lessonId": "..."}`. نفس الـ id والعنوان بيفضلوا، والنسخة القديمة بتتحفظ في `lessons/_backup/`.

## تغيير الصوت (CARTESIA_VOICE_ID)
تعديل `.env` بيتطبّق **فورًا من غير ريستارت** (السيرفر بيعيد قراءة الملف لما يتغيّر، والملف له الأولوية على متغيرات النظام). الصوت المخزّن في قاعدة البيانات مربوط بالـ Voice ID، فتغييره بيولّد صوت جديد (والقديم بيفضل متخزّن). `GET /api/health` بيعرض `tts_voice` الشغّال حاليًا. لو Cartesia رفض الـ ID بيرجع صوت المتصفح، والسبب بيظهر في Console المتصفح.
